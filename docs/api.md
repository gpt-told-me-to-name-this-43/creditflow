# API v1: коды ошибок

Все ошибки `api` возвращаются в одном формате (design.md §3.7):

```json
{"error": {"code": "REVISION_CONFLICT", "message": "Заявка изменена, обновите страницу"}}
```

`details` — необязательный массив `{loc, msg, type}`, есть у `VALIDATION_ERROR`. Источник истины —
`ErrorCode` и `ERROR_STATUS` в `api/app/schemas/common.py`; тест `test_error_codes_documented`
падает, если код есть в enum, но не описан здесь.

| `code` | HTTP | Когда | Текст для пользователя |
|---|---|---|---|
| `UNAUTHORIZED` | 401 | Нет токена, токен истёк или подпись неверна | Войдите заново |
| `INVALID_CREDENTIALS` | 401 | `POST /auth/login`: неверный логин **или** пароль (неразличимо, #5) | Неверный логин или пароль |
| `FORBIDDEN` | 403 | Роль не допускает эндпоинт (клиент на `/manager/*`) | Недостаточно прав |
| `APPLICANT_NOT_AUTHORIZED` | 403 | Привязка: ИНН и ФИО пользователя не совпадают с руководителем/ИП по реестру | Подать заявку может только руководитель компании или сам ИП |
| `NOT_FOUND` | 404 | Объект не существует **или принадлежит другому клиенту** | Не найдено |
| `REVISION_CONFLICT` | 409 | `revision` в запросе не совпадает с текущей | Заявка изменилась, обновите страницу |
| `INVALID_STATUS_TRANSITION` | 409 | Переход не разрешён FSM (design §3.7) | Действие недоступно в текущем статусе заявки |
| `IDEMPOTENCY_IN_PROGRESS` | 409 | Запрос с этим `Idempotency-Key` ещё выполняется | Запрос уже обрабатывается, подождите |
| `COMPANY_ALREADY_BOUND` | 409 | Компания уже привязана к другому пользователю | Компания уже привязана |
| `USER_ALREADY_BOUND` | 409 | У пользователя уже есть привязанная компания | К учётной записи уже привязана компания |
| `VALIDATION_ERROR` | 422 | Тело, query или path не прошли схему | Проверьте введённые данные |
| `INVALID_INN` | 422 | ИНН не 10/12 цифр или неверная контрольная сумма | Проверьте ИНН |
| `COMPANY_NOT_IN_REGISTRY` | 422 | ЕГРЮЛ/ЕГРИП ответил 404 | Компания не найдена в реестре |
| `CONSENT_REQUIRED` | 422 | Нет согласия или устаревшая версия текста (ПД при привязке, БКИ при Submit) | Подтвердите согласие |
| `ACTION_NOT_ALLOWED` | 422 | Действия нет в `allowed_actions` (например, `APPROVE` при стоп-факторе) | Действие недоступно для этой заявки |
| `AMOUNT_ABOVE_LIMIT` | 422 | Оффер: сумма больше `limit_for_term(term)` | Сумма превышает доступный лимит на этот срок |
| `SIGN_CODE_INVALID` | 422 | Неверный, истёкший или использованный код подписания | Неверный код подтверждения |
| `IDEMPOTENCY_KEY_REUSED` | 422 | Тот же `Idempotency-Key` с другим методом, путём или телом | Повторите действие |
| `TOO_MANY_ATTEMPTS` | 429 | Rate limit входа или > 3 попыток кода; есть `Retry-After` | Слишком много попыток, попробуйте позже |
| `PROVIDER_UNAVAILABLE` | 503 | Только сбой ext-sim (таймаут 3 с + 1 повтор); заявка остаётся в `DRAFT` | Внешний сервис недоступен, повторите позже |
